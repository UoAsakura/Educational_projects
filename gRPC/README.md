Последовательность создания и запуска взаимодействия по gRPC

Инсталируем нужные пакеты:
pip install grpcio grpcio-tools

Создаём .proto файл.

Генерируем Python код из .proto файла:
python -m grpc_tools.protoc -I. --python_out=. --grpc_python_out=. example.proto

Создаём сервер (server.py) и клиент (client.py).

Запускаем сервер и клиент.

Объяснение происходящего:
  - .proto файл: Определяет сервис и сообщения, которые будут использоваться для взаимодействия между клиентом и сервером
  - сервер реализует сервис, описанный в .proto файле, и слушает входящие запросы на указанном порту
  - клиент подключается к серверу и отправляет запрос, получая ответ
