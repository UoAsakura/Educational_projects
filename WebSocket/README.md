Последовательность создания и запуска взаимодействия по протоколу WebSocket

Инсталируем нужные пакеты:
pip install websockets

Создаём сервер (server.py) и клиент (client.py).

Запускаем сервер и клиент.

Объяснение происходящего:
Сервер:
 - Использует websockets.serve для запуска WebSocket сервера на localhost:8765
 - Обрабатывает входящие сообщения от клиента и отправляет ответ.
 - Поддерживает несколько подключений асинхронно.
Клиент:
 - Подключается к серверу по адресу ws://localhost:8765
 - Отправляет сообщение серверу и ожидает ответа.
